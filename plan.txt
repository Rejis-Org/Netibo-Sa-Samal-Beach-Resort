UI CLEANUP PLAN
===============

RULES
- Ang UI kinahanglan parehas gihapon sa karon. Walay mausab sa itsura, walay makulang.
- Walay git commit o git add. Dili ko mag-commit.
- 1 section = 1 file. Dili mag daghan og files.
- Target ~150 lines kada file. Guide ra ni. Dili ni rason nga mutangtang og code o UI. Kung kinahanglan mas taas, ok ra.
- Walay usbon sa class names.
- Walay comments sa code.
- Status = checkboxes ra. Next step = unang [ ] o [~] gikan sa taas.
